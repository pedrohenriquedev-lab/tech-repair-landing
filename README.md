# 💻 Tech Repair Landing Page

Landing page desenvolvida para simular os serviços de uma empresa de assistência técnica em computadores, com foco em conversão de visitantes em clientes.

## 🚀 Sobre o projeto

Este projeto foi criado com o objetivo de praticar a construção de interfaces modernas e responsivas, aplicando conceitos de UX/UI e organização de layout.

Durante o desenvolvimento, busquei estruturar a página de forma estratégica, pensando na jornada do usuário — desde a apresentação dos serviços até o contato.

## ✨ Funcionalidades

- Seção de apresentação de serviços
- Destaque de benefícios para o cliente
- Layout responsivo (mobile-first)
- Design moderno com foco em conversão
- Estrutura organizada e sem frameworks

## 🧠 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript (Vanilla)

## 🎯 Objetivo

Desenvolver uma landing page com aparência profissional, focada em usabilidade e conversão, simulando um cenário real de negócio.
